# Reactive Shapes

An interactive browser-based audio-reactive 3D toy built with Three.js and Cannon-ES.

- **Microphone mode** — sound triggers groups of physics cubes that fall and stack on a 3D platform
- **Click mode** — click anywhere to spawn cubes with a shockwave impulse
- **Malleable surface** — drag to sculpt the platform; cubes interact with the deformed shape
- **6 color palettes**, live gravity/force controls, FPS-aware performance management

**Tech:** Three.js · Cannon-ES · Web Audio API · Vanilla ES Modules (no build step)
